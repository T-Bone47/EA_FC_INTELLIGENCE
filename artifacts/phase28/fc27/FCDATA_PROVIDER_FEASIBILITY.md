# FCData provider feasibility

Status **AWAITING_PROVIDER_PERMISSION**.

The [public About page](https://fcdata.io/about/) describes an item-ID catalogue with card statistics, PlayStyles and roles, plus platform-specific market observations and consumer tools for Evolutions, SBCs and squads. The [role methodology](https://fcdata.io/role-ratings/) describes editorial weighting. An editorial fit score has no authority to establish official Role eligibility or calibrate the V3.2 engine.

The [terms](https://fcdata.io/terms) describe personal use and restrictions on harmful automated access and resale. The public pages reviewed do not expose a documented data-feed contract granting this project storage, caching, display, API redistribution, derivation or artwork rights. EA's [Community API announcement](https://www.ea.com/games/ea-sports-fc/news/pitch-notes-fc26-community-api-update) and [connection guide](https://help.ea.com/en/articles/ea-sports-fc/community-api/) describe account connections for approved partners. Obtain the applicable FCData and EA-related permissions before scheduling any import.

When documentation and rights are available, an adapter can implement our existing ingestion interface for cards, card details, PlayStyles, roles, market observations and snapshot metadata. Its test inputs should model provider versions, UTC observation times and rights scopes. Any activated release must pin source, files and canonical membership, and must carry an independent card reference before recommendation can start.
