# Account integration

Login and registration use the existing authentication client and server routes. Private route redirects retain pathname, query and fragment. Switching between account forms retains return state. Return destinations are limited to local application paths. The account recovery panel reports current instance availability. Profile, saved players, squad records, feedback and Logout retain their existing authentication flows.

Password reset delivery, EA account linking and Google sign-in are unavailable capabilities on this instance. The workspace uses the existing backend session and permissions.
