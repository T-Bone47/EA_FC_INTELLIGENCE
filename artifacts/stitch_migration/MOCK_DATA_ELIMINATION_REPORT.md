# Live content audit

| Classification | Implemented examples |
|---|---|
| REAL_API_DATA | Card identities, overall ratings, published attributes, ranks, tactical fit, uncertainty, cohort counts, reported gameplay observations, optimizer receipts, squads and account records |
| STATIC_PRODUCT_COPY | Navigation, availability descriptions, pitch layout labels, supported control names |
| DESIGN_ONLY_FIXTURE | Disposable accounts and scoped browser fixture selections in verification scripts |
| UNSUPPORTED_CLAIM | Stitch example scores, win rate, performance telemetry, market prices, EA/Google authentication integrations, fixed latency and simulated optimization |

The React build incorporates no standalone Stitch HTML or Tailwind CDN code. The pitch updates from the real preview response. Overview history stores only the context of completed recommendations in browser-session storage, scoped by account. Card, role and market evidence retain the API's availability states.
