# Stitch versus live React

Ten owner-supplied reference screens were compared with Chromium captures. The capture sheet pairs the reference and the implementation. Full-page captures appear smaller in the sheet when the live result contains a longer candidate ladder or attribute table.

| Screen | Visual implementation | Difference from the reference |
|---|---|---|
| Overview | Sidebar, context bar, hero and 4-3-3 pitch above workspace modules | Account and analysis panels show real data or an empty state |
| Discover | Filter rail, football card tiles and table/list toggles | Local design uses initials and exact observed identities |
| Intelligence | Setup, ranked results and live explanation columns | Real candidates can produce a longer ranked ladder |
| Squad Lab | Controls, interactive pitch and preview intelligence | Keyboard assignment list stays available under the pitch |
| Comparison | Exact versions, context, reasons and aligned attribute table | Real available fields determine the table length |
| Squad DNA | Slot evidence, contributions and tactical matrix | Integrated directly into Squad Lab |
| Smart Upgrade Studio | Before/after replacements, measured fit and apply/undo | Integrated directly into Squad Lab |
| Evidence Lab | Cohort, sources, comparison and observation controls | No prediction accuracy or consensus visualization appears without sufficient evidence |
| Authentication | Two-panel account workspace and guest entry | Production form actions and recovery availability replace sample SSO |
| Profile | Account settings and saved-work panels | Current authenticated account and preferences populate the page |

The canonical navy/lime/cyan palette matches the design direction. Named fonts use system fallbacks where local copies are absent. The browser checks cover the 1600, 1440, 1280, 1024, 768, 390 and 360 px layouts.
