# Security, Privacy & Epistemic Integrity Policy

## 1. Credential & API Key Protection
- `.env` and `.env.*` (except sanitized `.env.example`) are excluded via `.gitignore` and never tracked.
- Gemini (`GEMINI_API_KEY`) and OpenRouter (`OPENROUTER_API_KEY`) credentials live strictly in server environment settings (`backend/core/config.py`) and are never injected into Vite client bundles or API responses.
- `redact_secrets()` strips Bearer tokens, `AIza...` keys, `sk-or-v1-...` tokens, GitHub PATs, and private keys before logging errors or provider notes (`safe_ai_public_summary()` tested in `test_phase41_5_agentic_coach.py`).
- Strictly enforces **free-only** LLM tiers (`ai_coach_free_only=True`, `ai_coach_allow_paid_usage=False`).

## 2. Authentication, IDOR & Context Anti-Spoofing
- Password hashing via `bcrypt`, JWT bearer tokens via `PyJWT`, strict SQL parameterization, and per-user rate limits (`test_security.py`).
- Every Phase 40/41/42 personal resource (sessions, matches, squads, decision windows, training plans, annotations) is strictly partitioned by authenticated `user.id`.
- `PersonalCoachOrchestrator._authorize_and_hydrate_context()` verifies client-supplied `CoachContextEnvelope` IDs (`squad_id`, `match_id`, `decision_id`) server-side against user ownership, scrubbing spoofed references and emitting `UNAUTHORIZED_OR_INVALID_*_CONTEXT` notices (`test_phase42_copilot_cv_training.py` verified).

## 3. Prompt & Tool Safety
- Prompt injection detection (`detect_prompt_injection`) intercepts credential extraction, system override, or SQL-bypass instructions cleanly without exposing raw prompts or executing tools.
- Squad mutations generated by Coach tools create a pending confirmation proposal (`PENDING_CONFIRMATION`) that executes **only** after explicit user approval (`POST /squad-proposals/{id}/confirm`) and supports reversible `Rollback`.

## 4. Multimodal Screenshot Redaction & Consent Gate (`42G`)
- **In-Browser Redaction First:** `ScreenshotRedactorModal.tsx` paints black redaction masks locally on HTML5 `<canvas>` and re-encodes pixels as JPEG (`0.86`) to strip EXIF metadata before transmission.
- **Explicit Separate Opt-In:** Both `redaction_confirmed=True` and `user_consent_media=True` are required independently of general text chat consent.
- **Server Rejection & Quarantine:** Missing redaction confirmation or media opt-in triggers `IMAGE_TRANSMISSION_BLOCKED_REDACTION_AND_CONSENT_REQUIRED`. Permitted images emit `CANDIDATE_MULTIMODAL_OBSERVATION_UNVERIFIED` and never modify database telemetry or Gamer DNA.

## 5. Gameplay & License Integrity
- Only permissive OSS training defaults (`YOLOX-S`, Apache-2.0) ship in default CV workflows; AGPL-3.0 dependencies (`Ultralytics YOLO`) are isolated behind explicit opt-in consent (`accept_agpl_copyleft=True`).
- Raw gameplay footage uploads (`data/video_research/`), `.phase27-runtime/`, and non-redistributable datasets (`data/fc27_research/raw/`) are excluded via `.gitignore`.
